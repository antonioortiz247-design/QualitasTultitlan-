# Kit multimedia web — Quálitas Cuautitlán Romero Rubio

Paquete independiente con los recursos multimedia del sitio web.

Incluye:
- Logotipos Quálitas, versiones horizontales, verticales, blancos y con slogan.
- Favicon y letragramas.
- Imágenes de portada, activación y socios comerciales.
- Logotipos de marcas del cotizador.
- Ilustración SVG de protección vehicular.
- Modelo 3D del vehículo en formato GLB.

No incluye código fuente, configuraciones, archivos administrativos ni credenciales.

Los archivos se conservaron desde la carpeta pública de recursos del sitio.
