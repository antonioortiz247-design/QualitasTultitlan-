# Kit multimedia del sitio — Quálitas Cuautitlán Romero Rubio

Copia organizada de los recursos gráficos y multimedia del sitio web. Los archivos se incluyen sin modificar sus rutas originales.

## Contenido
- Identidad: logotipos horizontales y verticales, versiones con slogan y letragramas.
- Marca: `Q-morado.png`, favicon, logotipos blanco y auxiliares.
- Imágenes: hero principal, activación, socios comerciales y logotipos de Chevrolet, Ford, Honda, Hyundai, Kia, Mazda, Nissan, Toyota y Volkswagen para el cotizador.
- Recursos visuales e interactivos: ilustración SVG de protección vehicular y modelo 3D `qualitas-prius.glb`.

## Iconos y tipografía
Los iconos de interfaz se importan desde `lucide-react`; son componentes de la dependencia y no archivos de imagen individuales. La tipografía Poppins se configura en el proyecto; no se encontraron archivos de fuente locales dentro de `public/`.

## Descarga
Abre el repositorio en GitHub, selecciona **Code → Download ZIP** y extrae la carpeta `public/kit-multimedia/`. También puedes abrir esta carpeta para consultar los archivos individualmente.
