# Quálitas Cuautitlán

Primera etapa frontend para landing pública de captación de leads de un agente/intermediario Quálitas en Cuautitlán.

## Scripts

- `npm run dev`
- `npm run lint`
- `npm run build`

Los datos comerciales reales deben sustituirse en `src/config/site.ts`; actualmente están marcados como DEMO.
