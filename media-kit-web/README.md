# Kit multimedia web — Quálitas Cuautitlán Romero Rubio

Copia organizada de los recursos multimedia ligeros del sitio, preparada para respaldo y para subirla a otro servicio de almacenamiento.

## Carpetas
- `logos/`: logotipos, Q-morado, favicon y letragramas.
- `images/`: fotografía de activación, socios comerciales y logotipos de marcas del cotizador.

## Iconos de interfaz
Los iconos de cámara, automóvil, motocicleta, búsqueda, navegación, WhatsApp, etc. se dibujan desde Lucide React en el código fuente; no existen como archivos PNG/SVG independientes que se puedan copiar aquí.

## Recursos que permanecen en public/
Los originales siguen en `public/`. Esta carpeta es una copia de respaldo, no cambia las rutas de producción.
Por tamaño, no se duplicaron aquí `public/images/hero-seguro-auto.png` ni `public/car-protection.svg`; ambos permanecen disponibles en sus rutas originales dentro de `public/`.
